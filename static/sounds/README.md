# Sound Effects

This directory contains sound effects for the portfolio site.

## Current Files

All 7 sound files are synthesized CC0 audio, generated by `scripts/generate-sounds.mjs`
using pure sine/pluck/sweep oscillators written in Node.js. No copyright, no attribution required.

To regenerate (e.g. after tuning the script):

```bash
npm run generate:sounds
```

## Sound Inventory

| File | Sound ID | Description |
|------|----------|-------------|
| `tick.mp3` | `timeline-tick` | Short mechanical click for timeline reveals |
| `pop.mp3` | `confetti-pop` | Soft bubble pop for GitHub chart |
| `key.mp3` | `typing-key` | Mechanical keyboard keypress for typing test |
| `complete.mp3` | `typing-complete` | Success chime for typing test finish |
| `start.mp3` | `game-start` | Ascending 3-beep sequence for game/Konami start |
| `gameover.mp3` | `game-over` | Descending sweep for game over |
| `click.mp3` | `ui-click` | Clean UI button click |

## Replacing with Custom Sounds

Drop replacement `.mp3` files with the same names. Keep files small:
- Clicks/ticks: < 15 KB
- Chimes/sweeps: < 30 KB

## License

## Fallback

The site works without these files — sounds fail silently via error handling in `sound.ts`.
